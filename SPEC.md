# ElevenLabs VST Plugin - UI Improvements Specification

## Overview

This specification covers UI improvements to the ElevenLabs Music VST Plugin, focusing on waveform visualization, sample history management, and drag-to-DAW functionality.

---

## 1. Waveform Visualization

### Current State
- Waveform display shows "No audio generated yet" even when audio is loaded
- Bug: `setAudioBuffer()` is never called after generation completes (see `PluginEditor.cpp:567`)

### Requirements

#### 1.1 Fix Waveform Display
- Call `setAudioBuffer()` with the loaded audio buffer after generation completes
- Waveform should display immediately when audio is available
- Keep existing peak-only visualization style (no RMS overlay)
- Maintain current color scheme: Primary (#0F3460), Accent (#E94560)

#### 1.2 Loading State Animation
- During generation, show a **horizontal gradient sweep** animation
- Gradient sweeps left-to-right repeatedly using accent color (#E94560)
- Animation replaces the static "No audio generated yet" placeholder during loading
- Animation stops and waveform renders when generation completes

#### 1.3 Playback Position Indicator
- Vertical line indicating current playback position
- **Stepped updates** at ~30ms intervals (existing timer rate)
- No smooth animation required

## 2. Sample History

### Requirements

#### 2.1 History Dropdown
- **Position**: Above the waveform display
- **Format**: Each item displays `Genre (Duration) - Date`
  - Example: "Electronic (30s) - Jan 27, 2024"
- **Behavior**: Simple scrollable dropdown, no search/filter capability
- **Navigation**: Dropdown only (no Previous/Next buttons)

#### 2.2 History Scope
- **Default**: Show only samples generated by this plugin instance ("This Project")
- **Setting**: Toggle in Settings dialog to show "All Samples" (global history)
- **Project Identity**: Each plugin instance generates a UUID on first load, stored in DAW state
  - Samples tagged with this UUID to associate them with the project

#### 2.3 Loading Behavior
- Selecting a history item **replaces** the current sample (no side-by-side comparison)
- **Audio only**: Does not restore prompt/genre/duration settings
- **No auto-play**: User must click Play to hear the loaded sample
- History dropdown auto-selects newly generated samples

#### 2.4 Cache Management
- **No auto-pruning**: Cache grows indefinitely
- **Manual clearing only**: "Clear Cache" button in Settings (existing)
- **No individual delete**: Only bulk clear option

## 3. Drag-to-DAW

### Requirements

#### 3.1 Drag Source
- **Waveform is draggable**: Click and hold on waveform to initiate drag
- **Hold threshold**: ~300ms hold initiates drag; shorter clicks are scrub operations

#### 3.2 Scrub vs Drag Interaction
- **Click (< 300ms)**: Sets playback position without starting playback
- **Click + Hold (>= 300ms)**: Initiates drag-to-DAW operation
- If already playing, scrub click continues playback from new position

#### 3.3 Drag Implementation
- **Method**: File-based OS drag using existing cached WAV file
- **File source**: Use cached file directly (UUID.wav from cache directory)
- **Visual feedback**: OS default drag image (file icon)
- **Disabled state**: Drag not available when no audio is loaded
  - Visual indication: Cursor does not change to grab hand when hovering empty waveform

#### 3.4 File Naming (for DAW import display)
- Format: `Genre_YYYYMMDD_HHMMSS.wav`
- Example: `Electronic_20240127_143022.wav`
- Note: Since using cached file directly, DAW will see UUID filename; friendly name is for future enhancement if copy approach is used

## 4. Storage & Persistence

### Requirements

#### 4.1 Cache Location
- **Global cache**: `~/Library/Application Support/ElevenLabsVST/Cache/` (macOS)
- **No project-embedded files**: Plugin references global cache via UUID

#### 4.2 Project State
- Store in DAW project state:
  - Current sample UUID
  - Plugin instance UUID (for history scoping)
  - User settings/preferences

#### 4.3 Missing Audio Handling
- When cached audio file is missing but referenced in project state:
  - Display prompt: "Sample missing. Regenerate?"
  - **One-click regenerate**: Uses exact same parameters (prompt/genre/duration)
  - Parameters retrieved from history.json entry

---

## 5. Window & Layout

### Requirements

#### 5.1 Resizable Window
- **Minimum size**: 400 x 350 pixels
- **Default size**: 500 x 450 pixels
- **Scaling**: Proportional scaling of all UI elements (buttons, text, dropdown, waveform)

#### 5.2 Layout Order (top to bottom)
1. Header (title)
2. History dropdown (new)
3. Waveform display
4. Status/error labels
5. Control buttons

---

## 6. Playback Behavior

### Requirements

#### 6.1 DAW Independence
- Plugin plays independently of DAW transport
- No sync to DAW tempo or play state

#### 6.2 Auto-Play
- **Disabled**: New samples do not auto-play
- User must click Play button to hear generated/loaded audio

#### 6.3 New Generation Behavior
- New generation **automatically replaces** current sample
- No confirmation dialog
- History dropdown auto-selects the new sample

---

## 7. Settings Additions

### New Settings

#### 7.1 History Scope
- **Setting name**: "Show samples from"
- **Options**: "This Project" (default) | "All Projects"
- **Persistence**: Stored in plugin settings (not per-project)

## 8. Technical Implementation Notes

### 8.1 Key Files to Modify
- `PluginEditor.cpp/h`: Waveform display, history dropdown, drag handling, loading animation
- `PluginProcessor.cpp/h`: Expose audio buffer to editor, instance UUID
- `AudioCacheManager.cpp/h`: History filtering by project UUID
- `StateSerializer.cpp/h`: Store instance UUID, history scope preference

### 8.2 Waveform Bug Fix
Location: `PluginEditor.cpp:567` (handleGenerationComplete)
```cpp
// Current: Waveform not updated
// Fix: Call waveformDisplay.setAudioBuffer() with the newly loaded buffer
```

### 8.3 Drag-and-Drop Implementation
- Use JUCE's `DragAndDropContainer` for drag initiation
- Use `performExternalDragDropOfFiles()` for OS-level file drag
- Track mouse-down time to differentiate click vs hold

### 8.4 Project Instance UUID
- Generate UUID on first `setStateInformation()` call if not present
- Store in plugin state (survives project save/load)
- Tag new history entries with this UUID

### 8.5 Loading Animation
- Use JUCE Timer for gradient animation (~60fps for smooth sweep)
- Linear gradient from left edge to right edge
- Cycle every ~1-2 seconds

## Acceptance Criteria

- [ ] Waveform displays correctly when audio is loaded
- [ ] Loading animation (gradient sweep) shows during generation
- [ ] History dropdown above waveform shows past samples (Genre + Duration + Date)
- [ ] History respects "This Project" / "All Samples" setting (default: This Project)
- [ ] Selecting history item loads audio into waveform (no auto-play)
- [ ] Click on waveform sets playback position (no play trigger)
- [ ] Click-and-hold on waveform (~300ms) initiates drag
- [ ] Drag uses cached WAV file for OS-level file drag
- [ ] Drag disabled when no audio loaded (visual indication)
- [ ] Window is resizable with min 400x350, default 500x450
- [ ] All UI elements scale proportionally on resize
- [ ] Missing audio prompts one-click regenerate
- [ ] New generations auto-switch and auto-select in dropdown
- [ ] Settings includes history scope toggle

## Testing

Manual acceptance testing only. No automated tests required.

### Test Scenarios

1. **Waveform Display**
   - Generate audio, verify waveform appears
   - Verify gradient animation during generation
   - Verify playhead moves during playback

2. **History**
   - Generate multiple samples, verify all appear in dropdown
   - Select past sample, verify it loads (no auto-play)
   - Toggle history scope in settings, verify filtering works

3. **Drag-to-DAW**
   - Click waveform briefly, verify position changes (no play)
   - Hold waveform 300ms+, verify drag initiates
   - Drop into Ableton, verify audio imports
   - Verify drag disabled when no audio

4. **Window Resize**
   - Resize window, verify all elements scale
   - Verify minimum size constraint works

5. **Missing Audio Recovery**
   - Clear cache while project references sample
   - Reload project, verify regenerate prompt appears
   - Click regenerate, verify same params used
